# Simple Calculator

A basic web-based calculator supporting addition, subtraction, multiplication, and division — built with plain HTML, CSS, and JavaScript.

## Features
- Standard button-grid calculator UI
- Keyboard support (numbers, operators, Enter, Backspace, Escape)
- Clear (C) and delete-last-digit functions

## How to run
Just open `index.html` in your browser, or serve it locally:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Why this project
A calculator is a classic beginner project for practicing event-driven UI logic and basic expression evaluation in JavaScript.
